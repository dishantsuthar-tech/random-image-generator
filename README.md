# Random Image Generator 🎲

A fun mini project built with **HTML, CSS, and Vanilla JavaScript**.

Click the button to generate a random Doraemon image at a random position and rotation, along with a sound effect.

## 🔗 Live Demo

[View Live Demo](https://dishantsuthar-tech.github.io/random-image-generator/)

## ✨ Features

- 🎲 Random image generation
- 📍 Random screen position
- 🔄 Random image rotation
- 🔊 Sound 
- 🖼️ Multiple image sources
- 🎨 Simple interactive UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## 📚 Concepts Practiced

- DOM selection and manipulation
- `createElement()`
- `appendChild()`
- `addEventListener()`
- Arrays & Objects
- `Math.random()` & `Math.floor()`
- Dynamic image creation
- Inline CSS manipulation
- Audio with JavaScript
- `window.innerWidth` & `window.innerHeight`

## 🎯 Purpose

Built as a hands-on JavaScript practice project to strengthen **DOM manipulation, randomization, arrays, objects, and dynamic element creation**.
